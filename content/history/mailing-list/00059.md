body: "<pre>Hi all,\n\nI am in the way of releasing the 0.4 version. It will be mainly minor \nimprovements in all parts of the application. Plus two features which have to \nbe tested and improved. The fact is I can’t do it myself, so if nobody takes \ncare of it we’ll have two choices, first not releasing a new version --- from \nmy point ov view it’s not very fair for all those who rely on distributed \npackages ---, other choice is to release with experimental stuff in it, and \nit is what I will do if nobody minds, even if it will disappoint some users \nwhen they’ll try features that are not really finished to implement. Pretty \nlong introduction :-)</pre><pre>\n\nHere are descriptions of the new features.\n\nRemote directories : to use it, you first need to export a set of \nfonts, &quot;File&gt;Export Fonts&quot; will let you select a tag and a directory an then \nexport all the tagged fonts in this directory with a fontmatrix.data file and \nPNG previews. Just push this directory somewhere on a reacheable net host \n(even localhost should be right). After that, set the url \nin  &quot;Preference&gt;Files and Folders&gt;Remote Dir&quot; to the location you have put \nthe font dir. Also set a &quot;Local Storage&quot; dir. It’s where the remote font \nfiles will be  saved to when selected in Fontmatrix. Now you should reboot \nFontmatrix to see these remote font items (and certainly file a bug report or \ntwo :-) ).\n\nCheck database : At least now that Fontmatrix Trunk is changing almost every \nday, there is a chance that your installation is broken. Run &quot;Edit&gt;Check \nDatabase&quot;, it will present you 3 tabs. &quot;Dead links&quot; could occur when you \nremove a fontfile somewhere without removing the font item from \nFontmatrix. &quot;Activated not linked&quot;, the font is tagged as Activated in \nFontmatrix but the symlink has disappeared from $home/.fontmatrix \ndirectory. &quot;Deactivated linked&quot; is the reverse. For all these problem you’ll \nbe offered actions, it will be up to you to say if the job is done properly \nor not.\n\nThanks\n\n-- \nPierre Marchand\n<a  rel=\"nofollow\" href=\"http://www.oep-h.com\">http://www.oep-h.com</a>\n\n\n_______________________________________________\nUndertype-users mailing list\n[email&#160;protected]\n<a  rel=\"nofollow\" href=\"https://mail.gna.org/listinfo/undertype-users\">https://mail.gna.org/listinfo/undertype-users</a>\n</pre>"
