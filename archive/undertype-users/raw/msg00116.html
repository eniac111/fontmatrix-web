Vous (The Peach) avez écrit :
> Hi all
> I've just finished writing a gentoo ebuild for the svn version of
> fontmatrix, but there're some dependencies I don't get if they are 1)
> working 2) stable 3) needed 4) used for?
>
> these (for what I've read in the INSTALL file) are:
> - m17n

Not working.

> - icu (is it http://www.icu-project.org/ ?)

Working. note that you need version >=3.8

> - harfbuzz

Working. You don’t need to bother about deps here, the source code is included 
in Fontmatrix source tree, as advised by the Harfbuzz project.

>
> did I miss anything?

Depends what you were looking for :)
I should document it at some point. The interest to activate these shaping 
engines is that you can have quite an idea of how your fonts will be used in 
applications which use these engines to achieve CTL (complex text layout).
ICU is, at least, known to be used in OpenOffice and Xetex.
Harfbuzz… well, it’s used in Qt & Pango, but not exactly the same as what’s 
made available in the GIT repo (at least for Pango afaik).
