Dear, dear, dear translators,

As we get closer to the release of a new version I would be actually glad to 
see translations updated. 
We’ve changed some bits of the build system to allow distribution of source 
files only even for translations, so here is how it’s expected to work from a 
translator point of view (the example is given for French, just adapt for 
your language after having checked that the lang code is available (see 
INSTALL file)) and with a clean checkout (for those of you who are willing to 
translate but have not an SVN account yet, please introduce yourself here)
[1]:
$svn co\
svn+ssh://[EMAIL PROTECTED]/svn/undertype/trunk/tools/typotek\
fontmatrix
$mkdir fontmatrix/build
$cd fontmatrix/build
$cmake ../ [here your preferred options] -DTRANSLATOR=fr
$make translation #update the TS file
$linguist ../src/messages/fontmatrix-fr.ts
$make install && /where/is/fontmarix #to check the translation
$cd ..
$svn ci /src/messages/fontmatrix-fr.ts\
 -m "Updated - French translation"

If there is anything that’s still not clear, please feel free to ask.
Thanks in advance

[1] It’s mostly copied from an explanation given to Alexandre Prokoudine 
previously, so just ask him to know if it’s work!
