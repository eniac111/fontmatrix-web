Few days ago, we made a Mac build to ease testing on this platform. It's
Windows turn by now! To be honest, building on Windows is not as trivial as on
Unix-like system. So we are more than happy to thank a thousand times the hero,
Jean Ghali, to provide you with this updated binary.

First of all have a look on the
[README](https://web.archive.org/web/2011/http://fontmatrix.net/archives/win/fontmatrix-win32-rev819.README)
which will give you the instructions to get the Fontmatrix program contained in
this [package](https://web.archive.org/web/2011/http://fontmatrix.net/archives/win/fontmatrix-win32-rev819.zip)
up and running.

Management code for Windows is not implemented yet (in fact not even
designed!), so you will end up with something more like an advanced font
viewer. We hope you'll find it a use as is anyway! Enjoy.
