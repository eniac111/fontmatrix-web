Do you run a revision superior to r261? (I secretly hope no)

rev 261). If you don’t want to bother with SVN, just wait for next weeks as 
we’re about to release a new version.

The way Fontmatrix imports fonts is not optimal (who said crap?). It explores 
the folder you indicate to find font files and the folders contained in this 
folder, but it stops here. To be honest, I was scared of what could happen 
with actual recursivity. There is already a bug report asking for 
improvements here. To import files, I prefer use drag and drop mechanism - 
see  http://www.fontmatrix.net/multimedia/fm_dnd.ogg
