[Undertype-users] Preparing next release

Pierre Marchand Mon, 25 Feb 2008 03:10:33 -0800 

Hi all,

I am in the way of releasing the 0.4 version. It will be mainly minor 
improvements in all parts of the application. Plus two features which have to 
be tested and improved. The fact is I can’t do it myself, so if nobody takes 
care of it we’ll have two choices, first not releasing a new version --- from 
my point ov view it’s not very fair for all those who rely on distributed 
packages ---, other choice is to release with experimental stuff in it, and 
it is what I will do if nobody minds, even if it will disappoint some users 
when they’ll try features that are not really finished to implement. Pretty 
long introduction :-)

Here are descriptions of the new features.

Remote directories : to use it, you first need to export a set of 
fonts, "File>Export Fonts" will let you select a tag and a directory an then 
export all the tagged fonts in this directory with a fontmatrix.data file and 
PNG previews. Just push this directory somewhere on a reacheable net host 
(even localhost should be right). After that, set the url 
in  "Preference>Files and Folders>Remote Dir" to the location you have put 
the font dir. Also set a "Local Storage" dir. It’s where the remote font 
files will be  saved to when selected in Fontmatrix. Now you should reboot 
Fontmatrix to see these remote font items (and certainly file a bug report or 
two :-) ).

Check database : At least now that Fontmatrix Trunk is changing almost every 
day, there is a chance that your installation is broken. Run "Edit>Check 
Database", it will present you 3 tabs. "Dead links" could occur when you 
remove a fontfile somewhere without removing the font item from 
Fontmatrix. "Activated not linked", the font is tagged as Activated in 
Fontmatrix but the symlink has disappeared from $home/.fontmatrix 
directory. "Deactivated linked" is the reverse. For all these problem you’ll 
be offered actions, it will be up to you to say if the job is done properly 
or not.
