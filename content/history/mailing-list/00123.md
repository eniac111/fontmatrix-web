body: "<pre>Hello undertype-users,\n\n \nIntroduction</pre><pre>\n\nW3C is collecting ideas for work related to downloadable fonts on the Web. This \nemail summarizes the current situation, and asks for feedback on a draft \ncharter [0] for a future W3C Font working group or interest group. Please send \nfeedback on the charter to the publicly archived mailing list [email&#160;protected].\n\nBackground\n\nThe method of linking to fonts from CSS stylesheets or from SVG content - \nWebFonts - is already standardized in CSS2 [1] and SVG 1.1 [2]. That work is \nbeing refined in the CSS3 Fonts module [3], for the CSS serialization. SVG 1.1 \nallows both CSS and XML serialisations of WebFonts. SVG Tiny 1.2 uses the XML \nserialisation. XSL may use the WebFont mechanism in future, in the XL \nserialization.\n\nCSS2 WebFonts allows for font matching, font synthesis, and font download. of \nthose, only font download has been implemented in multiple user agents.\n\nWhat has hindered deployment, however, has been the choice of what font format \nto download. \n\nCSS2 suggests several formats, none of them being required for compliance. \nMicrosoft implemented WebFonts in IE4, using the then-proprietary EOT encoding \nof an OpenType font. EOT (and the related MicroType Express format) have since \nbeen documented in a submission to W3C [4] with the promise of royalty-free \ncommitments, if the EOT and MicroType Express formats form part of a W3C \nRecommendation. \n\nSVG requires one format (SVG fonts) and allows others to be linked. Adobe \nimplemented WebFonts in ASV, supporting SVG and CFF (a subset of OpenType, \nusing only Type 1 glyphs). Apache implemented WebFonts in Batik, supporting the \nSVG format. Opera implements WebFonts with SVG, and the fonts may be applied to \nSVG, HTML, or mixed SVG/XHTML content.\n\nSeveral Web browsers now implement WebFonts, with the OpenType format: Firefox \n3.5 (beta 4 was tested), Safari 3.1 and 4, and Opera 10 (alpha). W3C has \nproduced tests for complex international script rendering with downloadable \nfonts; the test and results are available [5]. (Firefox 3.5 beta 4 results are \nyet to be added to this table).\n\nFont licenses vary. Some fonts, libre, are provided with source code and permit \nextension, modification, and redistribution. The Open Font Library [6] collects \nsuch libre fonts. Other fonts may be downloaded and used, but may not be \nchanged, subsetted, or converted to another format. (Often such fonts are \ncontained in zip files; being able to link to a specific font inside a zipfile \nis desirable).\n\nSome fonts are licensed to a specific site or domain. EOT provides one way to \nindicate this in the font itself. Cross Origin Resource Sharing (CORS, \npreviously known as Access Control) is a W3C specification which may also be \nused to indicate this [7]. Mozilla Firefox restricts downloadable OpenType \nfonts to those permitted by CORS.\nThere may be other ways to indicate metadata, so that foundries and font \nlicensees may indicate the nature of their agreement.\n\nLastly there are of course fonts intended for use exclusively with print, whose \nlicenses explicitly preclude use on the Web.\n\nPlease take a moment to read and comment on the proposed charter [0] which is a \nwork in progress.\n\n[0] <a  rel=\"nofollow\" href=\"http://www.w3.org/2009/03/fonts-wg-charter\">http://www.w3.org/2009/03/fonts-wg-charter</a>\n[1] <a  rel=\"nofollow\" href=\"http://www.w3.org/TR/2008/REC-CSS2-20080411/fonts.html\">http://www.w3.org/TR/2008/REC-CSS2-20080411/fonts.html</a>\n[2] <a  rel=\"nofollow\" href=\"http://www.w3.org/TR/SVG11/fonts.html\">http://www.w3.org/TR/SVG11/fonts.html</a>\n[3] <a  rel=\"nofollow\" href=\"http://dev.w3.org/csswg/css3-fonts/\">http://dev.w3.org/csswg/css3-fonts/</a>\n[4] <a  rel=\"nofollow\" href=\"http://www.w3.org/Submission/2008/01/\">http://www.w3.org/Submission/2008/01/</a>\n[5] \n<a  rel=\"nofollow\" href=\"http://www.w3.org/International/tests/tests-html-css/tests-webfonts/results-font-linking\">http://www.w3.org/International/tests/tests-html-css/tests-webfonts/results-font-linking</a>\n[6] <a  rel=\"nofollow\" href=\"http://www.openfontlibrary.org/\">http://www.openfontlibrary.org/</a>\n[7] <a  rel=\"nofollow\" href=\"http://www.w3.org/TR/access-control/\">http://www.w3.org/TR/access-control/</a>\n\n-- \n Chris Lilley                    mailto:[email&#160;protected]\n Technical Director, Interaction Domain\n W3C Graphics Activity Lead\n Co-Chair, W3C Hypertext CG\n\n\n_______________________________________________\nUndertype-users mailing list\n[email&#160;protected]\n<a  rel=\"nofollow\" href=\"https://mail.gna.org/listinfo/undertype-users\">https://mail.gna.org/listinfo/undertype-users</a>\n</pre>"
