If you have a lot of fonts, the problem is also for users to have very long 
lists of fonts in their applications. A solution could be, if it fits well 
with font licence, to let users import fonts in Fontmatrix from some shared 
directory (NFS or SMB mounted dir). Fontmatrix will _copy_ fonts 
in "$HOME/.fonts-reserved/". I don’t know too much for feisty package but 
malex said "[...]and Ubuntu gutsy in our repositories on scribus.net and 
tagancha.org. These are the only branches that have recent enough Qt4 [...]"
indicating that you’d need to have an out distro Qt4 to compile Fontmatrix.
If you need help to do this, just come to #fontmatrix at freenode for a live 
support :)

> Speaking of which, does anyone know where the best location is to save the

It’s rather a matter of 1/ XFS (the X font server) 2/ fontconfig
