date: 2011-03-16
kind: news
original: http://fontmatrix.be/node/53
---

It's been 1.5 years since release of the latest version, 0.6.0. The project is
not very active at the moment, because its principal developer, Pierre
Marchand, is rather busy with other things. SVN trunk is currently ca. 150
commits away from 0.6.0 and features a rather simplified user interface with
few new features like named filters. The new user interface is not yet
finished, with some of the former tabs currently being floating windows.
Eventually we will finish the changes in UI, document them and release the next
version.
