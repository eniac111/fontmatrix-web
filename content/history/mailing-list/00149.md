body: "<pre>\n[SVN revision 1207]\n</pre><pre>\n\nFolks,\n\n\nI've just built and installed your fontmatrix program which has great\npotential IMHO.  However, there are still maaaaaaaany rough edges.\nI'll try to comment on all issues which I've noticed so far.\n\nThis sentence in the SVN log:\n\n  Changed minor version to 9, so we are aiming a 1.0 release. \n\nis unfortunately not justified yet IMHO.\n\n\no At the very first startup, it takes a long time to scan all fonts.\n  It would be nice if fontmatrix could display a rotating cursor, a\n  counter, or something similar to indicate that the program doesn't\n  hang.\n\no The idea to display the font name with the font's glyphs is nice,\n  however, it has severe problems.  See\n\n    <a  rel=\"nofollow\" href=\"http://groff.ffii.org/groff/temp/missing-glyphnames.png\">http://groff.ffii.org/groff/temp/missing-glyphnames.png</a>\n\n  for an example.  In other words, fontmatrix should check whether the\n  font actually contains ASCII glyphs, otherwise it should use a\n  fallback font to display the font name.  Maybe it should even check\n  whether the returned glyph images (a) contain black pixel at all and\n  (b) aren't all equal in case the font is badly defined.\n\n  In my opinion, this bug is a real showstopper.\n\no A very important filter is missing IMHO: The possibility to specify\n  the covered Unicode ranges.\n\no The font sample text should be selected using the font's Unicode\n  range information or the available OpenType scripts and language\n  tags.  Otherwise you get results as shown in\n\n    <a  rel=\"nofollow\" href=\"http://groff.ffii.org/groff/temp/wrong-sample-text.png\">http://groff.ffii.org/groff/temp/wrong-sample-text.png</a>\n\no If I click on a font, then selecting `Chart', I would like that this\n  view mode stays for all future fonts.  Currently, clicking on a new\n  font always starts with `Sample'.\n\no Similarly, if I select a block like `View all mapped glyphs', it\n  should stay also.  It's tiresome to select this again and again.\n\no There is a lot of overlapping in some fonts within the chart, see\n\n    <a  rel=\"nofollow\" href=\"http://groff.ffii.org/groff/temp/overlapping-glyph-info.png\">http://groff.ffii.org/groff/temp/overlapping-glyph-info.png</a>\n\n  Maybe this is hard to circumvent; in that case it would be nice if\n  the `big' image of a glyph (after clicking on it) displays those\n  overlapping info too.\n\no In the previous image you can also see\n\n    Block (318%)\n\n  which is funny, but irritating: Block data is useless IMHO for\n  unmapped glyphs.\n\no If I scroll down the font chart a bit, and the currently displayed\n  upper left glyph is, say, `acute', it would be nice if selecting a\n  different shape doesn't change this upper left glyph, and I still\n  see `acute'.  Currently, the font chart is reset so that the scroll\n  bar is at the top again.\n\no The function mode of the `Browse Directories' button is nice but\n  very irritating.  I've never seen a program before which behaves\n  like that.  At least, after pressing the button, the text should\n  change to `Return' or something.\n\no What the heck is sample `C'?  I see Russian text...\n\no I'm missing a font cascade mode.\n\no The sample texts should contain digits also.\n\no The layout for the sample text is buggy: There must be a minimal\n  spacing between words, see\n\n    <a  rel=\"nofollow\" href=\"http://groff.ffii.org/groff/temp/buggy-sample-layout.png\">http://groff.ffii.org/groff/temp/buggy-sample-layout.png</a>\n\n  It's quite hard to read\n\n    IchwarHerrimHaus.IchhättmeineTochtermehrcoramnehmen\n\n  in the middle of the image.\n\no I'm missing an `English' sample text.\n\no Doing\n\n    &lt;click on a font&gt; -&gt; Samples -&gt; Add\n\n  immediately crashes fontmatrix on my GNU/Linux box.\n\no The menu\n\n    Service -&gt; Show TrueType tables\n\n  should be greyed out at top level.\n\n\nI can only repeat: fontmatrix will become a great application, but\ncurrently it is far away from a 1.0 release.\n\n\n  Hope this helps\n\n\n    Werner\n\n_______________________________________________\nUndertype-users mailing list\n[email&#160;protected]\n<a  rel=\"nofollow\" href=\"https://mail.gna.org/listinfo/undertype-users\">https://mail.gna.org/listinfo/undertype-users</a>\n</pre>"
