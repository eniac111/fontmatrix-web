Here is how i would like FM and I act together.
(My dreams are beyond this).
 A friend uses FM and has prepared an export file on cd for me with all the
fonts i'll have to use for the job he's asking me.

choose if i want to import all of them or only a few ones.
I take all. Then FM highlights duplicates : I've allready Arial.ttf but it's
a 2.0 version and the cd has a 3.0 version. About Times.ttf, it's the
contrary because i own 3.0 and the import proposes V. 2.0. It lets me
compare (seeing both together) the 2 versions to be sure they are full sets
and exclude a "fine tuned version" that would have been modified by
Fontforge in a bad way. Then i choose what to do with each : add (even if
same name)/ replace /ignore the import font.
All these fonts are then marked as being part of JOB_N°X so i can find them
all back easily.
I activate them and work.
I miss a Script font.
I search all the fonts ON the pc to find a font name containing script, or a
tagged one named script. Not happy with what i find, i'll search my NAS
directory. I browse it (included zip files). I keep searching because i'm
sure i must have the one i search. It was in my printed FontBook version
that remains at my job's office. Well, i don't use it to much because
1- i change to often my font collection : it increases, i delete some
oldies, i buy some new ones, i replace ttf by otf... Always having to print
all the fontbook isn't really needed, and if i only print the new ones, they
are not sorted by name. Btw, i do not usually search them by name, but more
by categories... Or anything else. It depends of the job. Because my folders
are allready dividing my fonts according the alphabetical order.
2- I don't have a printer at home ((true).
Back to job, just have to find this font back where i moved it...
