You can build Fontmatrix with an alternate Freetype by giving cmake the path 
of the Freetype you want to link against (though I can’t promise you won’t be 
forced to run Fontmatrix in an environment where the right Freetype lib would 
be loaded e.g.:"LD_PRELOAD=/the/freetype/lib.so fontmatrix"). So, if it does 
not break your actual installation, performing a system wide upgrade of 
Freetype might be the good option.

Note that Fontmatrix does not behave especially regarding memory eating so 
expect some severe slowdown if you run it on an old system where this well is 
quite rare :)
