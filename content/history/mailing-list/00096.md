body: "<pre>Dear, dear, dear translators,\n\nAs we get closer to the release of a new version I would be actually glad to \nsee translations updated. \nWe’ve changed some bits of the build system to allow distribution of source \nfiles only even for translations, so here is how it’s expected to work from a \ntranslator point of view (the example is given for French, just adapt for \nyour language after having checked that the lang code is available (see \nINSTALL file)) and with a clean checkout (for those of you who are willing to \ntranslate but have not an SVN account yet, please introduce yourself here)\n[1]:\n$svn co\\\nsvn+ssh://[EMAIL PROTECTED]/svn/undertype/trunk/tools/typotek\\\nfontmatrix\n$mkdir fontmatrix/build\n$cd fontmatrix/build\n$cmake ../ [here your preferred options] -DTRANSLATOR=fr\n$make translation #update the TS file\n$linguist ../src/messages/fontmatrix-fr.ts\n$make install &amp;&amp; /where/is/fontmarix #to check the translation\n$cd ..\n$svn ci /src/messages/fontmatrix-fr.ts\\\n -m &quot;Updated - French translation&quot;</pre><pre>\n\nIf there is anything that’s still not clear, please feel free to ask.\nThanks in advance\n\n[1] It’s mostly copied from an explanation given to Alexandre Prokoudine \npreviously, so just ask him to know if it’s work!\n\n-- \nPierre Marchand\n<a  rel=\"nofollow\" href=\"http://www.oep-h.com\">http://www.oep-h.com</a>\n\n\n_______________________________________________\nUndertype-users mailing list\n[email&#160;protected]\n<a  rel=\"nofollow\" href=\"https://mail.gna.org/listinfo/undertype-users\">https://mail.gna.org/listinfo/undertype-users</a>\n</pre>"
